2. No telemóvel, abra o mesmo site → Ligar Árbitro / TV → introduza o código acima. Ligue antes de alterar nomes ou pontos.

3. No OBS: Fontes → + → Navegador. Cole este URL; largura 680, altura 300. Posicione no canto superior esquerdo. Deixe desativada a opção de encerrar a fonte quando não estiver visível.

Publique este ficheiro como index.html no seu site para ligar o telemóvel e o OBS. O ficheiro local permite experimentar a interface. A ligação remota requer internet. Teste no clube antes do torneio.
